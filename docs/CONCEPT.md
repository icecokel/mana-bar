# ManaBar — 초기 컨셉과 목적

## 1. 프로젝트 목적
Claude와 Codex의 남은 사용량을 macOS 메뉴바에서 한눈에 확인하는 앱을 만든다.
각 서비스의 사용량 페이지를 반복해서 열지 않고, 작업 중 사용 가능한 여유와 한도 초기화 시점을 쉽게 파악하는 것이 목표다.

개인적으로 쓰기 편한 앱을 먼저 만들고, 다른 사용자도 설치해서 사용할 수 있도록 공개·배포한다.

## 2. 핵심 컨셉
AI 사용 가능량을 RPG의 ‘마나’로 표현한다.
픽셀 아트와 포션·마나 게이지를 활용해 실용적인 사용량 확인에 작은 재미를 더한다.
숫자의 가독성과 작업을 방해하지 않는 간결함을 우선한다.

## 3. 확정된 기본 구성
- macOS 메뉴바 앱
- 메뉴바 항목 하나 안에 Claude와 Codex를 나란히 표시
- 두 서비스의 잔여 사용량을 동시에 확인
- 서비스별 아이콘·색상·형태 등으로 구분
- 클릭하면 하나의 상세 패널이 열리고 각 서비스 정보를 분리해 표시

## 4. 초기 시각 디자인 방향
아래 내용은 구체화할 디자인 제안이다.

- Claude: 주황색 계열의 둥근 픽셀 포션
- Codex: 파란색 계열의 각진 픽셀 포션
- 각 포션 옆에 잔여 비율을 숫자로 표시
- 잔여량에 따라 포션 안의 액체 높이 변화
- 색상뿐 아니라 형태로도 두 서비스를 구분
- 상세 패널에는 서비스 이름, 마나 게이지, 제한별 잔여량과 초기화 시간 표시
- 캐릭터 표정이나 짧은 반짝임 등은 선택적인 재미 요소로 검토
- 숫자는 작은 크기에서도 읽기 쉬운 글꼴 사용

표시 예시: [Claude 포션 72% · Codex 포션 45%]
※ 예시 숫자는 실제 계정 데이터가 아니다.

## 5. 사용량 표시 원칙
- 실제로 확인 가능한 데이터를 기준으로 표시
- 정확한 잔여 토큰 수가 제공되지 않으면 잔여 비율이나 사용 한도를 사용
- 세션·주간 등 서로 다른 제한은 구분
- 메뉴바의 대표 숫자가 어떤 제한을 뜻하는지 명확히 안내
- 조회 실패·연결 끊김·오래된 데이터를 잔여량 0으로 표시하지 않음
- Claude와 Codex의 잔여량을 하나의 수치로 합산하지 않음

## 6. 배포 목표
다른 사용자도 설치해서 사용할 수 있는 완성된 메뉴바 앱을 배포한다.
npm 배포를 희망하지만, 실제 설치·업데이트 방식은 기술 설계 후 결정한다.

## 7. 다음 설계에서 결정할 사항
- 각 서비스의 사용량 조회 및 인증 방식
- 메뉴바에 표시할 대표 한도와 상세 패널 구성
- 데이터 갱신 주기와 오류·미연결 상태 표현
- 알림과 애니메이션 범위
- 구현 기술, 설치·업데이트 및 배포 방식

현재 단계는 컨셉 정의이며, 데이터 연동 가능 여부와 구현 기술은 아직 확정하지 않았다.
